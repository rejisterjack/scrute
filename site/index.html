Scrute reads your staged changes and asks Claude or GPT for a structured review, using your own API key. The source stays on your machine.

$ go install github.com/rejisterjack/scrute@latest

  1. 01Export ANTHROPIC_API_KEY or OPENAI_API_KEY.
  2. 02Stage with git add, then run scrute.
  3. 03Fix what matters. Push when the review is quiet.
